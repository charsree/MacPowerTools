# Mac Power Tools - Installation Instructions

## Quick Install (Recommended)

### 1. Install via Homebrew
```bash
# Add the tap
brew tap charsree/tools

# Install the app
brew install macpowertools

# Copy to Applications (works on Intel and Apple Silicon)
cp -r $(brew --prefix)/opt/macpowertools/MacPowerTools.app /Applications/

# Launch the app
open /Applications/MacPowerTools.app
```

### 2. Grant Permissions (Automatic)
The app will automatically request permissions when first launched:

**Screen Recording Permission:**
- Required for text extraction feature
- Click "Allow" when prompted
- Or manually: System Preferences → Privacy & Security → Screen Recording → Add MacPowerTools.app

**Accessibility Permission:**
- Required for global hotkeys and auto-paste
- Click "Allow" when prompted  
- Or manually: System Preferences → Privacy & Security → Accessibility → Add MacPowerTools.app

**Important:** Restart the app after granting permissions for full functionality.

### 3. Auto-Start Setup (Optional)
The app automatically adds itself to login items. To verify:
- System Preferences → Users & Groups → Login Items
- MacPowerTools should be listed

## Manual Build (Advanced)

### Prerequisites
- macOS 10.15+ with Xcode Command Line Tools
- Run: `xcode-select --install` if needed

### Build Steps
```bash
# Clone/download the project
cd MacPowerTools

# Build the app
chmod +x build.sh
./build.sh

# Create app bundle
chmod +x create_apps.sh
./create_apps.sh

# Install to Applications
cp -r MacPowerTools.app /Applications/
open /Applications/MacPowerTools.app
```

## Usage

### Keyboard Shortcuts
- **Cmd+Shift+T**: Extract text from screenshot
- **Cmd+Shift+V**: Show clipboard history and paste selected item

### Menu Bar
Look for the ⚡ lightning bolt icon in your menu bar for quick access.

## Troubleshooting

**App doesn't respond to hotkeys:**
- Grant Accessibility permission and restart app

**Text extraction not working:**
- Grant Screen Recording permission and restart app

**Clipboard items don't paste:**
- Ensure Accessibility permission is granted
- This permission is required for auto-paste functionality

**Permission reset (if needed):**
```bash
sudo tccutil reset ScreenCapture com.macpowertools.app
sudo tccutil reset Accessibility com.macpowertools.app
pkill MacPowerTools
open /Applications/MacPowerTools.app
```
